🏓 우리 동네 피클볼 코트 지도

피클볼 코트 위치를 지도에서 한눈에 찾아볼 수 있는 크라우드소싱 지도입니다. 누구나 지도를 눌러 자신이 아는 코트를 등록할 수 있어요.

🔗 바로가기: https://hi50years-create.github.io/pickleball-court-map/

기능
시/도, 시/군/구, 실내·실외, 이용방식(무료개방/예약필요/회원전용)으로 필터링
지도 아래 코트 목록 (이름순 정렬, 페이지네이션)
지도를 탭해서 새 코트 직접 등록
"확인된 코트"(운영자가 검증)와 "제보된 코트"(사용자 등록)를 색으로 구분 표시
사용 기술
Leaflet + OpenStreetMap — 지도
Firebase Firestore — 코트 데이터 저장
Kakao Maps 지오코더 — 주소 → 좌표 변환

별도 빌드 과정 없는 순수 HTML/JS 프로젝트입니다. index.html 하나로 동작해요.

코트 정보 등록하기
위 링크로 접속
지도에서 아는 코트가 있는 위치를 탭
코트 이름, 주소(선택), 실내/실외, 이용방식, 메모 입력 후 등록

등록한 정보는 운영자 검토 후 "확인된 코트"로 표시됩니다.

참고사항
지도 위 좌표는 대략적인 위치일 수 있어요. 정확한 위치는 코트명으로 한 번 더 검색해 확인해주세요.
이용방식(예약 필요 여부 등)은 시점에 따라 바뀔 수 있으니 방문 전 최신 정보를 다시 확인하시는 걸 권장해요.
개인이 운영하는 취미 프로젝트로, 상업적 목적이 없습니다.
